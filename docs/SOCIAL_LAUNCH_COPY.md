## Reddit / FlutterDev (technical, not just promotional)

**[Project] Jiva AI — Flutter-first Android assistant with explicit action confirmation (feedback welcome)**

I have been building an experimental open-source Android assistant in Flutter with a Kotlin platform integration layer.

Features include voice/typed commands, local reminders, optional Gemini BYOK, and opt-in accessibility actions that are deliberately restricted and confirmation-based.

The tricky parts are UI responsiveness, voice/provider differences across Android devices, secure API-key changes, and safe handoff to dialer/message apps.

I'd appreciate technical feedback, especially on Android lifecycle, permission design and reproducible build/test documentation.
