# Security Policy

Jiva is an experimental project; do not use it as a safety-critical service. Please do not report secrets, API keys, personal contact data, or exploit details in public issues.

## Reporting a security concern

For a suspected vulnerability, contact the repository owner privately through GitHub's available private vulnerability reporting feature (if enabled for this repository). If private reporting is unavailable, open a minimal issue asking for a private contact channel without including exploit steps or personal data.

Please include the affected version/commit, Android version/device class, impact, and a safe reproduction summary. Allow maintainers reasonable time to investigate before public disclosure. Do not test against devices, accounts, or services you do not own or have explicit permission to assess.

## User safety

- Never publish an API key, contact information, message content, or other private data in an issue, log, or screenshot.
- Revoke a Gemini API key immediately if it may have been exposed.
- Review permissions and source before installing a build from an untrusted fork.
